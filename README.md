# Определение токсичных комментариев для «Викишоп»

## Описание
Интернет-магазин «Викишоп» запускает сервис редактирования описаний товаров: пользователи могут предлагать правки и комментировать изменения других (как в wiki).  
Задача — построить модель, которая автоматически определяет токсичные комментарии и отправляет их на модерацию.

## Цель
По тексту комментария предсказать класс `toxic` (1 — токсичный, 0 — нетоксичный).

## Данные
- Текст комментария: `text`
- Целевая переменная: `toxic` (0/1)

## Метрика качества
- **F1-score** (основная метрика для бинарной классификации при возможном дисбалансе классов)

## Подход
1. Предобработка текста (очистка, приведение к нижнему регистру)
2. **Baseline-модель:** TF-IDF + LogisticRegression (Pipeline)
3. Сравнение с альтернативными моделями (опционально)
4. (Опционально) Модель на **BERT** и сравнение качества с baseline
